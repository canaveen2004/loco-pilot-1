# Loco Pilot Tamil Nadu (frontend + backend) Frontend: public/index.html (HTML + JS game). Backend: server.js (Node.js + Express). ## Run on your PC 1. Install Node.js 18+ (nodejs.org) 2. In this folder: `npm install` then `npm start` 3. Open http://localhost:3000 (Optional, for AI Control: set env ANTHROPIC_API_KEY before `npm start`) ## Free hosting (Render.com) Upload folder to GitHub -> Render "New Web Service" -> Build: `npm install`, Start: `npm start`. Add env var ANTHROPIC_API_KEY (optional). You get a URL like https://yourgame.onrender.com ## Make APK that uses the server In public/index.html add before the big ` Then zip public/ contents (index.html at root) and upload to AppsGeyser. ## API POST /api/login {name} | POST /api/progress {name,age,r,gen,score} | GET /api/leaderboard | POST /api/control {prompt} Notes: data.json storage (resets on free hosts that wipe disk). Scores come from the client, so cheating is possible.
